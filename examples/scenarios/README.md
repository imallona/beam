# Canonical simulated scenarios

`scenarios.qmd` is a simulated scenarios vignette. It runs the same report layout as the Duo walkthrough on four canonical simulated benchmarks with documented ground truth, so a regression in any pipeline primitive flips a documented assertion.

The four scenarios are generated by `beam.scenarios`:

- `random`: ARI and runtime drawn iid, then re-paired so the two metrics are anti-correlated. No method Pareto-dominates the rest; which method comes out on top depends entirely on the weighting. SMAA confidence is spread across the Pareto-frontier methods.
- `dominant`: one method dominates on every metric. It is ranked first under any weighting; SMAA confidence factor is 1; no single-criterion weight perturbation can move it off the top rank.
- `ties`: two methods produce identical scores on every metric. They share a rank under any weighting.
- `odd_dataset`: one method is best on most datasets, a different method is best on one odd dataset. Cross-dataset aggregation with the per-metric rule from the card picks the method best overall; the per-dataset signal is visible only by direct inspection of the tensor.

Each generator returns a `Scenario` carrying the pooled tool by metric matrix, the optional per-dataset tensor, the metric ids used, and a `ScenarioExpectation` documenting what the MCDA pipeline ought to report. Tests in `tests/test_scenarios.py` pin every pipeline primitive against one or more scenarios.
